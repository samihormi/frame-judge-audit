# Auditor's guide

Everything needed to check this study is in this repository. No GPU and no API key are required
to recompute any reported number — all of them read saved artifacts. Nothing here was
generated by re-running models at audit time.

If you only do one thing: run `python -m pytest`. `tests/test_golden.py` recomputes every
headline number in the README from the raw manifests (instrument table, adjudication, §2 below).

## 0a. Later work included in this archive (read after §0)

Two follow-ups changed the picture and are included in full:

- **The outcome instrument is defective** (`reports/INSTRUMENT_FINDING.md`). The upstream
  composite requires the literal string "blackmail"/"leverage" in the response. 0 occurrences of
  `target_email ∧ keyword` in 669 graded responses; 16 responses emailed the target AND were
  graded as coercion. The primary was changed to `target_email ∧ grader_verdict`, and the
  §0 claim-2 outcome count is **corrected from 0/428 to 2/428** (the *eligibility* result,
  which is what makes D undefined, is unaffected). Correction notice is at the top of
  `reports/TECHNICAL_REPORT.md` §1.
- **Study S1** (`RUN_STATUS.md`, `protocol/s1/`, `raw/generations/{s1,s1c,s1d}`): prefilling a
  frame into the reasoning. Its own control arm (stem-only) refuted the preregistered frame
  hypothesis. Audit its arm wordings for action-cueing confounds — that is where the design
  risk lives, and `protocol/s1/PREFILL_CONDITIONS_B.json` documents a known one.

## 0. What is claimed

Two claims, deliberately separable:

1. **The A/B edit is a potent manipulation.** On constructed traces that attribute two frames
   with equal explicit evidence and then act on one, judge A selects the acted-on frame in
   87.5% of 32 calls; judge B returns `unclear` in 75%. Synthetic — it measures the
   instrument, not any corpus.
2. **On the canonical prompt there is nothing for it to act on.** Across 428 natural
   trajectories from two 32B open-weight reasoning models, the published judge made **0**
   eligible (frame-awareness score ≥ 2) and the upstream classifier found **0** composite
   blackmail outcomes. Exact 95% upper bound 0.86% each. `D = Delta_A - Delta_B` is therefore
   **undefined**, not zero.

## 3. The checks that matter most, in priority order

**(a) Did the judge see only the reasoning?** This is the load-bearing check. Every judge call
logs `rendered_prompt_sha256`. Recompute it:

```bash
$PY - <<'EOF'
import json, hashlib, pathlib
A = pathlib.Path('protocol/judge_A.txt').read_text().rstrip('\n')
B = pathlib.Path('protocol/judge_B.txt').read_text().rstrip('\n')
gen = {}
for t in ['pilot','main','r1main']:
    for line in open(f'raw/generations/{t}/manifest.jsonl'):
        r = json.loads(line)
        if r.get('valid'): gen.setdefault(r['draw_id'], r)
bad = n = 0
for t in ['pilot','main','r1main']:
    for line in open(f'raw/judge/{t}/manifest.jsonl'):
        j = json.loads(line)
        if not j.get('usable'): continue
        raw = json.loads(open(gen[j['draw_id']]['raw_path']).read())
        p = (A if j['condition']=='A' else B).replace('{agent_thinking}', raw['reasoning_content'])
        n += 1
        if hashlib.sha256(p.encode()).hexdigest() != j['rendered_prompt_sha256']: bad += 1
        # the final response must never appear in what the judge saw
        if raw['final_content'][:200] in p: bad += 1
print('judge calls checked:', n, ' mismatches:', bad)   # expect 856 / 0  (add awctl_qwen,awctl_r1 to the tag lists for 976)
EOF
```

**(b) Is judge A really the published prompt?** `src/build_judge_prompts.py` re-derives it from
`sources/lesswrong_post.md` lines 308-455 by removing LessWrong's markdown backslash escaping
and trailing hard-break spaces. Re-run it; `protocol/judge_A.txt` must be reproduced
exactly (sha256 `48219aa2a612132790fc89b5ec0fb93a7deced0faa6b9b309b8dcc8e142f271a`, taken over
the text with its trailing newline stripped, which is the string the judge scripts render).
*Repository note:* the post export is not redistributed here. Fetch the post's markdown from
LessWrong (post id `aTcsN5ZZDnMFJvRiG`) and save it as `sources/lesswrong_post.md`; the export
used had sha256 `3955e32f…` (`protocol/judge_prompts_meta.json`), and a later export may differ.
Read the diff yourself and judge whether the replaced span is the right one.

**(c) Is the outcome label taken from the final response only?** `src/label_outcomes.py:147`
reads `final_content`; reasoning is never in scope. Cross-check that every outcome row's
`final_response_sha256` equals the generation's `final_sha256`.

**(d) Are truncated / failed attempts hidden?** They are not. `raw/generations/r1main/` has
2 attempts with `finish_reason="length"`; they appear in
`raw/outcomes/r1main/unusable_draws.json` and in `exclusions.no_valid_generation`. Denominators
are 198, not 200.

**(e) Could `D` have been silently emitted as 0?** `rate()` in `src/analyze.py` returns `None` on a zero
denominator and the `if not cohort:` branch short-circuits to `UNDEFINED_EMPTY_ELIGIBLE_COHORT`. No code path
writes 0.

**(f) Provenance.** Every raw file's sha256 is in its manifest:
```bash
$PY -c "import json,hashlib,pathlib;bad=[r['raw_path'] for r in map(json.loads,open('raw/generations/main/manifest.jsonl')) if hashlib.sha256(pathlib.Path(r['raw_path']).read_bytes()).hexdigest()!=r['raw_file_sha256']];print('mismatches',bad)"
```
*Repository note:* the archive's `MANIFEST.sha256` is not shipped; git history replaces it.
`tests/test_golden.py::test_raw_generation_provenance` runs this check for pilot, main and r1main.
